# Project Context

This is a personal, self-hosted project. Dev and production run on the same machine.

## Inference
All LLM inference is local. Use the same endpoint and model that Pi itself is using for this session.

## Principles
- Minimal dependencies
- Privacy-first, no external services unless explicitly requested
- Self-hosted everything

## Web Deployment
The web UI is served from a separate machine on the local network. Build with that boundary in mind.
